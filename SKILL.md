# Браузер: Chrome для DeepSeek Harness

Навык подключает к харнесу готовый сервер [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
(Google). После установки и перезапуска у тебя появляются инструменты двух браузеров:

| Инструменты | Какой Chrome |
|---|---|
| `mcp__chrome_sandbox__*` | отдельный: свой профиль `~/.dsh/chrome-profile`, без входов человека; сервер сам открывает его при первом вызове |
| `mcp__chrome__*` | основной Chrome человека — его вкладки и аккаунты; работает, когда человек включил удалённую отладку |

Правила работы с браузером (какой выбирать, что подтверждать) установщик дописывает в `~/.dsh/AGENTS.md`, их ты
видишь в каждой сессии. Этот файл — про установку, проверку и починку.

**Папка навыка** — та, где лежит этот `SKILL.md`. Ниже `<навык>` — её полный путь.

## Если человек прислал ссылку на GitHub

1. Скачай навык в папку навыков:
   - нет `~/.dsh/skills/browser` → `git clone https://github.com/PiedPiperMoney/browser-skill ~/.dsh/skills/browser`;
   - уже есть → `git -C ~/.dsh/skills/browser pull --ff-only`.
   Нет `git` — скачай архив `https://github.com/PiedPiperMoney/browser-skill/archive/refs/heads/main.zip` и распакуй
   так, чтобы `SKILL.md` лежал прямо в `~/.dsh/skills/browser/`.
2. Дальше — «Установка» ниже, `<навык>` = `~/.dsh/skills/browser`.

Команды пишут вне рабочей папки (`~/.dsh`) и качают из интернета — харнес может спросить человека. Это нормально:
коротко объясни, что ставишь, и жди его ответа. Если в текущем режиме разрешений запись туда запрещена совсем —
попроси человека запустить команду в терминале сам и дай её одной строкой.

## Установка

Нужно: macOS или Linux, Chrome 144 или новее, Node.js 22.12+ (или приложение DeepSeek Harness — у него свой Node),
`npm`, интернет.

1. Скажи человеку одной фразой, что сделаешь: поставишь сервер браузера в `~/.dsh/mcp`, сторож и правила в `~/.dsh`,
   допишешь подключение в профили харнеса.
2. Запусти: `bash <навык>/install.sh`. Скрипт сам находит профили (`desktop` — приложение, `web`, `headless`);
   повторный запуск ничего не дублирует.
3. Ошибку скрипта не обходи вручную — перескажи человеку и предложи, что сделать (поставить Node.js, запустить
   приложение один раз, обновить Chrome).
4. Передай человеку два шага, которые можешь сделать только он:
   - **перезапустить DeepSeek Harness** — инструменты браузера появятся после перезапуска;
   - для работы **в его Chrome** — открыть там `chrome://inspect/#remote-debugging`, включить галочку удалённой
     отладки и нажать «Разрешить», когда Chrome спросит. Без этого работает только отдельный Chrome.
     Ссылку `chrome://` из чата открыть нельзя — её вставляют в адресную строку.
5. Предложи после перезапуска написать «проверь браузер».

## Проверка

1. `bash <навык>/install.sh --check` — что установлено и открыт ли порт основного Chrome.
2. Нет инструментов `mcp__chrome_sandbox__*` в этой сессии — значит, харнес не перезапущен после установки.
3. Отдельный Chrome: `new_page` с `https://example.com`, по ответу назови заголовок, `take_screenshot`, закрой вкладку.
4. Основной Chrome — только если человек включил галочку: то же в `mcp__chrome__*`. Чужие вкладки не трогай,
   закрывай только свою.
5. Скажи человеку, что работает, а что нет и почему.

## Если не работает

| Признак | Что делать |
|---|---|
| Нет инструментов `mcp__chrome…` | Перезапустить харнес. Не помогло — `install.sh --check`, затем переустановить. |
| Основной Chrome: ошибка подключения, порт закрыт | Галочка в `chrome://inspect/#remote-debugging` выключена или Chrome закрыт. Попросить включить. Не подменять отдельным Chrome без спроса. |
| Подключение висит | Chrome ждёт «Разрешить» — попросить нажать. |
| Порт не 9222 | Посмотреть порт на странице `chrome://inspect/#remote-debugging` и переустановить: `DSH_CHROME_PORT=<порт> bash <навык>/install.sh`. |
| Вызов отклонён «requires approval» | Это сторож: ввод, скрипт, загрузка файла в основном Chrome требуют «да» человека. В режиме полного доступа такие вызовы отклоняются всегда — сказать человеку. |
| Отдельный Chrome не открывается | Chrome не установлен в обычное место или занят профиль `~/.dsh/chrome-profile` — закрыть лишнее окно Chrome с этим профилем. |

## Обновление и удаление

- Обновить: `git -C <навык> pull --ff-only`, затем `bash <навык>/install.sh`, затем перезапуск харнеса.
- Удалить: `bash <навык>/install.sh --uninstall`, перезапуск харнеса. Папку навыка и профиль отдельного Chrome
  (`~/.dsh/chrome-profile`) удаляй, только если человек попросит.

## Чего не делать

- Не включай удалённую отладку в Chrome за человека и не запускай его Chrome с флагами отладки сам — это его
  настройка безопасности.
- Не управляй браузером в обход этих инструментов (AppleScript, `open`, запуск Chrome из терминала).
- Не меняй файлы навыка у человека, кроме обновления через `git pull`.
