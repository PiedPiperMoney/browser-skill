# Браузер — Chrome для DeepSeek Harness

Навык для **DeepSeek Harness**. Он даёт агенту DeepSeek настоящий Chrome. Агент открывает вкладки и адреса, читает
текст и структуру страницы, кликает, вводит текст, делает скриншоты и выполняет JS. Примерно так же Claude работает
через расширение Claude in Chrome.

- **Два браузера.** По умолчанию агент работает в **отдельном Chrome**: у него свой профиль, ваших входов там нет.
  В **вашем Chrome**, с вашими вкладками и аккаунтами, — только когда вы так скажете: «в моём хроме», «под моим
  аккаунтом». Если задаче нужны ваши входы, а вы не уточнили, агент спросит.
- **Видно, что он делает.** По странице едет синий курсор с подписью «Клик», «Ввод», на клике расходится круг, по
  краю вкладки светится рамка. На скриншотах агента курсора нет.
- **Опасное — только с вашего «да».** В вашем Chrome ввод текста, загрузку файлов, выполнение скриптов и Enter
  останавливает сторож и спрашивает вас. Оплату, отправку форм, публикации, удаление и согласие с условиями агент
  подтверждает у вас по правилам. Пароли и данные карт вводите только вы.

Работает на готовом сервере [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) от Google,
который харнес подключает как MCP-сервер. Сам харнес навык не меняет.

Учтите: всё, что агент читает на странице, уходит модели DeepSeek. Не просите его открывать то, что не хотите ей
показывать.

## Установка — одной фразой

Напишите агенту в DeepSeek Harness:

> Подключи браузер: https://github.com/PiedPiperMoney/browser-skill

Агент скачает навык в `~/.dsh/skills/browser`, спросит разрешение и поставит всё нужное. Потом останется два шага руками:

1. **Перезапустите DeepSeek Harness.**
2. **Для работы в вашем Chrome** откройте в нём `chrome://inspect/#remote-debugging` (адрес вставьте в адресную
   строку), включите галочку удалённой отладки и нажмите «Разрешить», когда Chrome спросит. Без этого работает
   только отдельный Chrome. Порт отладки Chrome открывает только на вашем компьютере (127.0.0.1).

После перезапуска напишите **«проверь браузер»**.

### Вручную

```
git clone https://github.com/PiedPiperMoney/browser-skill ~/.dsh/skills/browser
bash ~/.dsh/skills/browser/install.sh
```

Затем те же два шага. Проверить, что стоит: `bash ~/.dsh/skills/browser/install.sh --check`.
Обновить: `git -C ~/.dsh/skills/browser pull` и снова `install.sh`. Удалить: `install.sh --uninstall`.

## Что нужно

- DeepSeek Harness: приложение или `npx @deepseek-ai/dsh`.
- Chrome 144 или новее.
- Node.js 22.12 или новее с `npm` ([nodejs.org](https://nodejs.org), версия LTS). У приложения DeepSeek Harness свой
  Node, тогда системный нужен только ради `npm`.
- macOS или Linux. Проверено на macOS.

## Как просить

- «Открой example.com и скажи заголовок» — отдельный Chrome.
- «Найди на сайте … и сделай скриншот» — отдельный Chrome.
- «Открой **в моём хроме** YouTube Studio и посмотри последние комментарии» — ваш Chrome.
- «Что у меня открыто в хроме?» — ваш Chrome, только чтение.

## Что ставится

| Где | Что |
|---|---|
| `~/.dsh/skills/browser/` | этот навык (инструкция для агента и файлы) |
| `~/.dsh/mcp/chrome-devtools/` | сервер chrome-devtools-mcp 1.11.0 и прослойка с курсором `visual-proxy.mjs` |
| `~/.dsh/browser/` | сторож опасных действий `guard.mjs` и `hooks.json` |
| `~/.dsh/profiles/<профиль>/cordis.patch.yml` | блок `# browser:start … # browser:end`: два сервера и сторож |
| `~/.dsh/AGENTS.md` | блок правил: какой браузер выбирать, что подтверждать |
| `~/.dsh/chrome-profile/` | профиль отдельного Chrome |

## Как устроено

- **Ваш Chrome** подключается по адресу `ws://127.0.0.1:9222/devtools/browser`. Его открывает галочка в
  `chrome://inspect/#remote-debugging`. Штатный режим сервера `--autoConnect` на macOS не работает: система не пускает
  сторонние программы в папку Chrome, где лежит файл с адресом. Другой порт задаётся так:
  `DSH_CHROME_PORT=<порт> install.sh`.
- **Курсор** рисует прослойка `visual-proxy.mjs` между харнесом и сервером. Перед действием она выполняет на
  странице небольшой скрипт. Тот рисует курсор в закрытом слое поверх страницы, клики проходят сквозь этот слой.
  Список инструментов и ответы сервера не меняются. Действия становятся медленнее примерно на полсекунды. Выключить
  курсор: дописать `--no-cursor` перед `'--'` в `chrome.cordis.yml` и запустить `install.sh`.
- **Сторож** — хук `PreToolUse` харнеса (`guard.mjs`). Он отвечает «спросить человека» на ввод, скрипты, загрузку
  файлов, перетаскивание, диалоги и Enter в вашем Chrome, а в обоих браузерах — на ввод, похожий на пароль или
  данные карты. В режиме полного доступа харнес такие вызовы отклоняет.
- **Набор инструментов.** Замеры скорости, эмуляция устройств, сеть и память отключены, чтобы не тратить токены.
  Остаются вкладки, переходы, снимок страницы, клики, ввод, скриншоты, JS и консоль.

## Ограничения

- Капчи агент не проходит, а просит вас.
- Расширения Chrome и PWA навык не трогает: эти разделы сервера выключены.
- Каждый браузер добавляет к запросам описания своих инструментов, это примерно 20 КБ на браузер.
- Safari не поддерживается: у него нет такого протокола управления, как у Chrome.
